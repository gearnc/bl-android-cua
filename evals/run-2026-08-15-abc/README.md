# A/B/C, 15 August 2026 — 36 runs

6 apps × 3 arms (hybrid / bare / acli) × 2 replicates, Normal capability, ~30 machine-verifiable
tasks each, one app per child session. Hybrid/bare is comparable with `evals/baseline-2026-08/`
and `evals/run-2026-08-14-abc/`; **acli has no history before 14 August** — do not read an acli
number against the archived two-arm baselines.

## What was measured

- plugin: `main` @ `5ec78b6` — includes the focused-field render from #16, verified by grepping
  the child snapshot's plugin cache for it rather than assumed
- accessibility-cli: `0.1.0` @ `03cfeb3db1ecd37375f370edfe86b8ffbfa9037f`, `cargo install`ed by
  the org blueprint, `--version` checked in a child before launch
- emulator: Android 14 / API 34, 720x1280 @320dpi, F-Droid APKs preinstalled
- apps: markor, amaze (Views), seal, unitto (Compose), joplin, lesspass (React Native)
- pre-launch: `test_dumps.py` rc=0 for all six matrix apps, `test_acli.py` `problems=none` for all
  six (per-app `--llm` observation 29–749 chars against `hd see`'s 427–2,685)

## Headline

Ratios against bare — ACU: hybrid **0.98x**, acli **1.06x**. Perception tokens: hybrid **0.84x**,
acli **0.90x**. Iterations: hybrid **0.99x**, acli **1.06x**. Tasks done: hybrid **1.00x**, acli
**0.98x**. Screenshots (mean): hybrid 4.8, bare 19.1, acli 13.4.

Billed input — the integral of resident context over turns, which is what ACU tracks — moves the
other way: median run hybrid **1.12x** bare, acli **1.25x**. A cheaper look is not a cheaper run.
Hybrid takes 3.24 looks per task against bare's 2.38 at 477 perception tokens per look against
1,727; across the 24 hybrid/bare cells one extra look per task prices at 0.077 ACU per task.
`report.md` is the full writeup.

## Validity

- all 36 cells settled in `waiting_for_user` with structured output; none graded from prose
- **bare-arm mode**: mixed, and closer to visual CUA than the previous run. At ≤5 screenshots =
  improvised tree tooling and ≥20 = visual CUA: 2/12 improvised tooling, 4/12 did visual CUA,
  6/12 in between; median 10 screenshots over ~30 tasks. So this run is nearer *skill vs. visual
  computer use* than *skill vs. agent-improvised tree tooling* — the flattering framing. Re-check
  the split every run; it has flipped between runs of the same matrix.
- **acli adoption**: 12/12 acli cells invoked the binary; no cell dropped. 308 of the invocations
  went through a wrapper script the agent wrote, so literal-name counts are a floor.
- **bypass balance**: runs writing device state directly are 3/12 hybrid, 5/12 bare, 6/12 acli —
  close enough that the ACU comparison stands, though acli's edge is in the direction that would
  flatter it.
- the plugin was not modified and acli was not rebuilt between launch and collection. The
  `hd tap "PAT"` verb in this PR was written after collection finished and is NOT in the measured
  revision.

## What the run justified changing

115 of the hybrid arm's 236 look-only commands, in 12/12 of its runs, were a look followed by
nothing but `hd tap <index>`: a turn bought only to number a target the agent could already name.
The acli arm never paid it (195 `--click`/`--type` selector actions). Hence `hd tap "PAT"`, priced
in `evals/test_tap_label.py`.

## Files

- `runs.json` — cell → session id (the sessions are the ultimate audit trail)
- `state.json` — final state, ACU and completion detail per cell
- `metrics.json` — ACU, perception/context/billed tokens, iterations, exec calls, screenshots
- `tasks.json` — n_done / n_partial / n_failed per cell
- `bypass.json` — UI-bypassing shortcut commands per cell
- `exec_commands.json` — every captured `shell_process_started` command, per cell; the adoption,
  verb-mix, focus-hunt and label-resolution sections of the report are derived from it
- `report.md` — generated by `evals/make_report.py` from the files above
