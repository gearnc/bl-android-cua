# A/B/C, 16 August 2026 (second matrix of the day) — 36 runs at `477c380`

6 apps × 3 arms (**hybrid / bare / raw**) × 2 replicates, Normal capability, ~30
machine-verifiable tasks each, one app per child session. **No `acli` arm was run and no archived
`acli` number is quoted here.** Hybrid/bare is comparable with `evals/baseline-2026-08/`; `raw`
has history only in `evals/run-2026-08-16-abc/` (the earlier matrix at `0bfdb63`), so its ratios
are quoted inside this run.

## What was measured

- plugin: `main` @ `477c380` (the merge of #21, delta-shape), containing **both**
  `skills/android-hybrid-navigation` and `skills/android-raw-navigation` — verified by grepping a
  throwaway child's plugin cache for revision-specific symbols (`gone_line`, `collapse_moves`) and
  for the raw skill's `SKILL.md`, not assumed from the snapshot date
- emulator: Android 14 / API 34, 720x1280 @320dpi, F-Droid APKs preinstalled
- apps: markor, amaze (Views), seal, unitto (Compose), joplin, lesspass (React Native)
- arms differ by exactly one paragraph (`suites.ARM_HYBRID` / `ARM_BARE` / `ARM_RAW`): `bare` is
  denied both skills and `hd`, `raw` is denied only `android-hybrid-navigation`/`hd` and told to
  read `android-raw-navigation`'s SKILL.md itself. Neither the wrapper nor any command was pasted
  into a prompt.
- the plugin was not modified between launching the matrix and collecting it. The `hint_pattern`
  and `test_dumps.py` changes in the same PR as this archive were written **after** collection and
  are NOT in the measured revision.

## Headline

Ratios against bare — ACU: hybrid **1.04x**, raw **0.91x**. Perception tokens: hybrid **1.15x**,
raw **0.53x**. Billed input (median run): hybrid **1.28x**, raw **0.86x**. Screenshots: hybrid
**0.42x**, raw **0.16x**. Tasks done: hybrid **0.99x**, raw **1.01x** (27.7 / 28.1 / 28.2 of ~30).

**Hybrid did not win this matrix.** The method alone (`raw`) got the cost reduction; `hd`'s
machinery on top of it did not, and on Compose it cost 1.32x bare in both ACU and perception.
Tail: ACU CV 0.33 hybrid / 0.47 bare / 0.48 raw — the variance reduction the raw arm's thesis
predicts shows up in perception (CV 0.31 vs. bare's 0.56) and screenshots (0.58 vs. 1.43), not in
ACU.

## Validity

- **bare arm's perception mode**: mixed, and this is the caveat on every bare ratio — 3/12 runs
  improvised tree tooling (≤5 screenshots), 2/12 did visual CUA (≥20), 7 in between; median 10
  screenshots. 11/12 wrote or ran their own dump wrapper, first at command 2–64. So this is
  mostly *skill vs. agent-improvised tree tooling*.
- **raw arm adoption**: 12/12 used the method (781 wrapper/`uiautomator dump` invocations, first
  at command 2–13). **Contamination: 0/12 invoked `hd`.** No cell was dropped.
- **bypass**: runs writing device state directly — 4/12 hybrid, 5/12 bare, 6/12 raw; no arm did
  materially less work.
- **dump preflight**: `test_dumps.py` reported no `problems` for any app, but several apps' dump
  commands exited non-zero (they read files a freshly installed app has not created) and the
  script did not fail on that, so the playbook's "rc=0 for every app" was not strictly met. The
  trees dumped and the final state dumps graded cleanly, so the matrix stands. The PR that adds
  this archive makes `test_dumps.py` exit non-zero on it so a future matrix cannot launch this way.

## Mechanism (what the PR acts on)

The hybrid arm spent **147 of its 291 look-only commands** (11/12 runs) on a standalone look
followed by nothing but `hd tap <index>` — a turn bought purely to turn a label it could already
name into a number. The verb that removes it, `hd tap "PAT"`, was typed on **1 of 917 taps (0%)**,
down from 126/781 at `b3898c3`. The in-tool hint added after the previous run fires, so the
suggestion itself is the suspect: it printed the node's *whole* label, up to 391 characters on
these six screens, and 17 of 95 suggestions contained a regex metacharacter, so `tap_pattern`
would raise on the line as printed. See `evals/bench_hint_pattern.py`.

Two other hybrid-side costs are unfixed and priced here for the next PR: 56 focus-hunting commands
in 10/12 runs (26 of them React Native, the stack where hybrid runs furthest above bare), and
hand-rolled backspace-count deletion loops in 3/12 runs.
